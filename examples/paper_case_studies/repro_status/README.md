# Cross-platform reproduction status

Live numerical comparison of the paper case-study runs across platforms.
Each machine contributes one file — `metrics_<platform>.csv` — generated by
`collect_metrics.py` from its local `SYMFLUENCE_data` tree, and commits only
that file (no merge conflicts between machines):

```bash
python examples/paper_case_studies/repro_status/collect_metrics.py \
    --platform macos --root /path/to/SYMFLUENCE_data
git add examples/paper_case_studies/repro_status/metrics_macos.csv
git commit -m "repro: update macos metrics" && git pull --rebase && git push
```

`comparison.csv` is regenerated automatically (currently by the Windows box's
monitoring loop) from all `metrics_*.csv` present: per-`experiment_id` deltas
between every platform pair, flagged `DIFF` when |Δ| exceeds the tolerance
(0.02 KGE — the cross-platform noise bound stated in
`04_calibration_ensemble/README.md`), plus the aggregate reference checks from
the experiment READMEs. Do not edit `comparison.csv` by hand.
